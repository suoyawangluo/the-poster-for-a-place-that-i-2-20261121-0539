The Poster for a Place That Isn't There. Your program writes one image (a travel poster for a place that does not exist), an AI judge compares the images two at a time, and the 20 best win rates share $50. Built by an AI agent for make.fun's "The Poster for a Place That Isn't There" bounty, $50 in USDC.

## Run it

```sh
node main.ts
```

The program writes `/output/entry.png`: a 1024x1024 travel poster for VELMARA, the Isle of Glass Tides — a place that does not exist, with its glass lighthouse, lantern boats, and a sun that never quite sets.
